# Viewing and editing pages

Pages always open in **view mode**: you read the content without typing into it by accident, and opening a page does not change it (it does not change "last edited by" or create a new version).

## Edit a page

1. Click **Edit** at the top right of the page (shown only when you can edit in the Space).
2. The title, icon and content become editable; the cursor is placed in the content.
3. Every change is **saved automatically** as you type — the **Saving… / Saved** status shows progress. Others who have the page open see your changes at once.
4. Click **Done** to go back to view mode.

A new page (no content yet) opens in edit mode.

## Good to know

- **Done** is not a save button: the content is already saved as you type. If you click Done before saving finishes or while offline, the status stays visible until everything is saved.
- To get older content back, use **Version history** (the clock icon next to Edit).
- In view mode, Mermaid diagrams show only the drawing, not the code.
- People who can only view the Space do not see **Edit**.
